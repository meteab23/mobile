# Stride — B2B BNPL

Modern B2B Buy Now Pay Later web app inspired by [Billie](https://www.billie.io) product structure and [OpenAI](https://openai.com) visual restraint.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS v4
- Framer Motion
- Lucide icons

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Surfaces

| Route | Description |
| --- | --- |
| `/` | Marketing landing |
| `/demo` | Book a demo |
| `/checkout/demo` | Buyer Pay Later checkout |
| `/dashboard` | Merchant overview |
| `/dashboard/invoices` | Invoice ledger |
| `/dashboard/buyers` | Buyer credit limits |
| `/dashboard/settings` | Merchant settings |
