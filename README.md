# Mizan — AI Personal CFO for the UAE

A modern, fully interactive personal finance web app inspired by Hiro Finance, adapted for the UAE with AED demo data.

## Features

- **Chat-first AI CFO** — ask about net worth, spending, goals, and what-if scenarios with verifiable math panels
- **Financial Plan** — long-horizon projections with baseline / growth / cautious scenarios and milestone tracking
- **Portfolio Analyst** — net worth chart, allocation, top movers, side-by-side chat
- **Accounts** — Emirates NBD, FAB, ADCB, Sarwa, Rain, Emirates Islamic mortgage, Marina property + connect flow
- **Cashflow** — income / expenses / surplus charts and July spending mix
- **Goals** — emergency fund, villa down payment, Hajj, education, FI — with interactive contributions
- **Settings** — household, nudges, export & support (demo)

## Stack

- Next.js (App Router) · React · TypeScript · Tailwind CSS · Recharts · Lucide

## Run

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
